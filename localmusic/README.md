# LocalMusic для iPhone (PWA)

**[Открыть LocalMusic и добавить на iPhone](https://nikolasmagith.github.io/localmusic/)**

Открой ссылку **в Safari на iPhone**, нажми «Поделиться» → «На экран Домой» → «Добавить». Apple ID разработчика, AltStore, Mac и USB не нужны. Первое открытие требует интернет; после кэширования интерфейса приложение может работать офлайн.

MP3 импортируются с устройства, остаются в локальном хранилище браузера и не отправляются на сервер. Не удаляй оригиналы: очистка данных Safari может стереть локальную библиотеку. Фоновое воспроизведение на заблокированном iPhone не гарантировано. Это не IPA и не нативное приложение.

Чтобы скачать исходники проекта ZIP-архивом, открой [репозиторий GitHub](https://github.com/NikolasMaGitH/NikolasMaGitH.github.io) и выбери **Code → Download ZIP**.
