# LocalMusic PWA 1.0 — веб-приложение для iPhone без Apple ID

## Что это
Это **отдельная реализация** интерфейса LocalMusic для Safari (не нативный IPA). Использует обычные HTML, CSS и JavaScript, без библиотек, удалённой аналитики, рекламных SDK, аккаунта или музыкальных серверов.

Доступно: импорт локальных MP3, хранение копий в IndexedDB, удаление, плейлисты, добавление песни в один или несколько плейлистов, повтор песни, повтор списка, перемешивание, обратный порядок, перемотка, управление через Media Session там, где позволяет Safari.

## Как установить на iPhone
1. Публикуй содержимое этой папки **на HTTPS-сайте** (например GitHub Pages). Это не установщик .ipa и простой ZIP из приложения «Файлы» установить нельзя.
2. На iPhone впервые **с подключённым интернетом** открой URL в Safari и дождись полной загрузки. Перезагрузи страницу один раз, чтобы убедиться, что Service Worker завершил установку.
3. Нажми «Поделиться» → «На экран Домой» → «Добавить» / «Открыть как веб-приложение».
4. Запусти значок LocalMusic с главного экрана.
5. Нажми «+» → «Импортировать MP3» → выбери локальные файлы на iPhone в «Файлах». После импорта песня хранится в изолированном хранилище веб-приложения и не отправляется в сеть.
6. Отключи интернет и проверь повторное открытие, MP3 и плейлисты.

## Ограничения iPhone
- Это **не** нативное iOS-приложение. На iPhone Safari может ограничивать фоновое воспроизведение, Media Session и управление на заблокированном экране.
- При нехватке памяти или очистке данных сайтов iOS может удалить локальное IndexedDB-хранилище. **Не удаляй оригинальные MP3 и сохраняй резервные копии.**
- Само приложение не делает HTTP/API-запросов, но первая загрузка, Service Worker, обновления сайта и обслуживание браузера требуют/могут использовать сеть. Для строго физически изолированного от сети нативного плеера PWA не эквивалентен исходной концепции.
- Начальное открытие через HTTPS обязательно. Публикация на GitHub Pages делает **код** приложения публичным, но не музыкальные файлы: они остаются в браузере пользователя.
- Для добавления файла нельзя использовать ссылку на аудио, только выбираемые файлы `.mp3`.

## Размещение через GitHub Pages
Опубликуй `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и каталог `icons/` вместе в одну директорию на GitHub Pages, например `/localmusic/`. Путь должен быть **HTTPS**. Проверь доступность URL, прежде чем делиться ссылкой.

## Проверки
`node --check app.js`; можно локально просмотреть интерфейс с помощью `python -m http.server 8000`, но Service Worker полноценно проверяй на HTTPS. Для локального теста `localhost` является исключением из требования HTTPS, однако в этой версии регистрация SW выполняется только по HTTPS, чтобы избежать путаницы с недоступным офлайн-режимом.
